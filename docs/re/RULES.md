# Toyota Trafik Oyunu v2 — game flow, rules, scoring, questions, profiles

Source: static analysis of `work/ghidra/TrafikOyunu_v2.exe` (decompiles `game.c`/`game_lo.c`, objdump for constants).
Exact strings with addresses and screen grouping: `work/re/strings.json` (generated by `work/re/RulesRE/mkstrings.py`, decoded straight from the binary, CP1254).
Confidence tags: **[C]** confirmed from code, **[L]** likely, **[G]** guess. Runtime facts reported by Main are marked **[RT]**.

## 0. Key state (where things live)

`FormOyun` = `TFormOyun` instance, global `0x55d648` (via `PTR_DAT_0054b098`). Field names come from the published field table (`work/re/RulesRE/fields.py`).

| Field | Meaning |
|---|---|
| `FormOyun+0xee .. +0x1fc` | **current profile record**, the same 271-byte layout as UserData.dat (§2). So `+0x18f` (= rec+0xa1) **is the live score** ("Puan") |
| `+0x200` | current map 1..5 (1 Eğitim Sahası, 2 Kasaba, 3 Şehir, 4 Şehir Merkezi, 5 Otoban, debug only) [C] (`0x52fa18`, `0x52fa78`, builder strings) |
| `+0x204` | points required for this map [C] |
| `+0x20c` | "menu mode": a `Menu` question is showing or about to show [C] |
| `+0x20d` | 1 means the Menu was opened by ESC (exit confirmation), 0 means the map was passed [C] |
| `+0x214` / `+0x218` | cutscene playing / its panel [C] (`0x50a7e4`) |
| `+0x1fd` | driver talking animation is playing; key input is ignored [C] |
| `+0xec` | mouse picking enabled (set to 1 at game start `0x52dca4`) [C] |
| `0x54a804` | paused flag (`FUN_00508250`); pause = `0x508120`, resume = `0x5081a8` [C] |
| `0x54a808` (double) | map elapsed seconds [C] |
| `0x54a814` (float) | map time limit in seconds (typed const, default 300.0, overwritten by each builder) [C] |
| `0x5531e8[4]` (int) | **per-map score at the last pass**, maps 1..4. Session-only, never loaded from disk [C] (`0x530770`, `0x535b18`) |
| `0x55de5c` | a question panel is open (`DAT_0055de5c`/`PTR_DAT_0054b05c`) [C] |
| `0x553084` / `0x553085` / `0x553086` | report visible / "Enter pressed" / map to load after the report [C] |

HG.vdd flags read at unit init `0x50a1c0..0x50a1f6` (top-level keys, absent from the shipped HG.vdd) [C]:
- `Demo` → `0x54a7fc`, default **False**. Debug mode: in the licence quiz, Ctrl+P passes immediately (`0x517780`); all map buttons are enabled (`0x5175e0`); in-game keys `1`..`5` load map N and `7`/`8`/`9` play the fail/2nd-stage/game-end cutscenes (`0x52e49a`, `0x52ff8c`).
- `Logo` → `0x54a800`, default **True**. Branded build: uses `bolumler\maps\Logo\` textures, `_yaris_L.mpg` videos, shows the key panel and the ">> Sonucu TOYOTASA'ya yolla..." option on map 4.

## 1. Menu flow (TGirisForm)

1. Start screen. `SpeedButton1` caption "Başlamak için resme tıklayın..." (`0x517a48`). Clicking it opens the help panel `paGiris` (`0x517fec`): images `maps\giris.jpg`, `levha_puan.jpg`, `ihlal_isik.jpg`, `ihlal_cop.jpg`, `ihlal_park.jpg`, `ihlal_yaya.jpg`, with the texts at `0x51825c..0x51871c` [C].
2. Closing the help (`SpeedButton7` → `SpeedButton14Click 0x517fcc`) enables `Timer1` (15 ms). This plays the intro animation `0x515e60`: the menu traffic light goes red → yellow at tick 20 → green at tick 50; at tick 70 it starts music `sesler\trafik_ses2.mp3` and shows the driver list `Panel2` (unless a driver is already chosen). Decorative cars `maps\araba01..12.bmp` scroll from tick 90 on [C].
3. Driver list `lb1`. On first paint the game reads every UserData.dat record and adds the item `name + ' ' + surname` (`0x515510`, separator ShortString `0x515e5c`). Item i is record id i+1 [C].
   - "Tamam" (`SpeedButton10Click 0x516a54`) loads record ItemIndex+1 (`0x5346e0`: seek id-1, read 271 bytes) into `FormOyun+0xee`. A negative score is clamped to 0. Required quiz answers become **3 if the licence flag is set, otherwise 8** [C].
   - "Yeni Sürücü" opens `Panel3`. "Tamam" there (`SpeedButton9Click 0x516670`) validates the form. Checks run city, then surname, then name, so the message of the last failing check stays in `Label11`. Success requires only name and city; **surname is not required** (the code checks Edit1 twice — a bug). On success it builds a record: id = -1 (append); name = Edit1, surname = Edit2, city = Edit3 (each truncated to 50); age = cb1.ItemIndex+1 (items '1'..'100', default index 11 = 12); score 0; licence 0; unlocked maps 1. It saves the record (§2) and sets required answers to **8** [C].
4. Main panel `Panel1`: "Sürücü Belgesi" (quiz), "Araç Sürme" (map selection), "İletişim" (popup menu), "Bilgi" (opens `bilgi.html` via ShellExecute, `0x517f28`), "Müzik Listesi" (playlist form), "Başa Dön" (`0x5173d0`, reset to the start screen; also clears the edits and the quiz). The top image `SpeedButton2` sets ModalResult 2, which quits the game [C].
5. "Araç Sürme" (`0x5175e0`) shows `paHaritaSecim` ("Baslamak için harita seçiniz." — DFM caption, not translated at runtime). `btHarita1` is always enabled. `btHarita2..4` are enabled when the **unlocked count `rec+0xa6` ≥ 2/3/4**; in Demo mode all are enabled [C].
6. Map button (`Button1Click 0x517c40`, map = button Tag 1..4):
   - If the session licence flag `GirisForm+0x450` is 0: MessageBox "Oyunu oynayabilmek için önce "Sürücü Belgesi" düğmesine basarak 10 sorudan " + N + " tanesini doğru yanıtlamalısın." with caption "Uyarı", where N = required answers (8 or 3). **The licence must be re-earned every program run**: `+0x450` is cleared in FormCreate and is not persisted. Only the persisted `rec+0xa5` lowers the requirement from 8 to 3 [C]. This explains the observed "8" then "3" [RT].
   - Otherwise it stops the menu music, sets `FormOyun+0x200` = map, saves the profile and sets ModalResult 1. `TFormOyun.DataModuleCreate 0x52da18` then starts the game (`0x52dc8c`) [C].

### 1.1 Licence quiz ("Sürücü Belgesi", `SpeedButton3Click 0x51707c`)
- Loads SoruBank (`0x534234`, §4). It scans records in file order until the first record whose category ≠ `'Ehliyet'` (ShortString compare with `0x5343e4`). That gives **NE = 71 Ehliyet questions (records 0..70)** and NT = 79 Trafik questions. It resets the 3 "recent" slots `0x55d8f0[3]` to -1 [C].
- Next question (`0x516b64`): asked counter `GirisForm+0x44c` += 1. It draws a random record from `Random(NE)` and redraws while the index is in a recent slot. **Bug:** the slot index `0x55d8fc` is never written, so only slot 0 is updated and only an immediate repeat is avoided [C].
- Answer shuffle: `Random(6)` picks a permutation. a1 is always the correct answer [C]:

  | r | line1 | line2 | line3 | correct line |
  |---|---|---|---|---|
  | 0 | a1 | a2 | a3 | 1 |
  | 1 | a1 | a3 | a2 | 1 |
  | 2 | a2 | a1 | a3 | 2 |
  | 3 | a2 | a3 | a1 | 3 |
  | 4 | a3 | a1 | a2 | 2 |
  | 5 | a3 | a2 | a1 | 3 |

  Lines are prefixed "a ) ", "b ) ", "c ) " (`0x517054/64/74`). The same table is used in game (`0x5332b8`).
- Rendering (`Timer1Timer`, `Image4` canvas):
  - Each string is wrapped at the last space before column 55, into at most 2 lines (`0x51770c`).
  - Pass 1 draws a gray `0x808080` shadow starting at y=22. Pass 2 draws the text starting at y=20, centered horizontally.
  - Line advance: +30 after the question, +20 after each answer, +20 per wrapped line.
  - Question colour `0x0000FF` (TColor = red). An answer is yellow `0x00FFFF` while hovered, otherwise black (`Image4MouseMove 0x5170a4`).
  - Hit rows are stored at `GirisForm+0x428/0x42c`, `+0x430/0x434`, `+0x438/0x43c` (y min/max for answers 1..3) [C].
- Click (`Image4MouseDown 0x517120`), only while the quiz is active (`0x553488`=1):
  - **Correct:** correct count `0x553490` += 1. A steering wheel `maps\direksiyon_k.bmp` is drawn on `Image5` at x = −48 + 50·correct, y = 0 (so x = 2, 52, 102, …). Score `rec+0xa1` **+10**. If correct == required → **passed**: `GirisForm+0x450`=1 and `rec+0xa5`=1. Else if asked == 10 → fail. Else next question [C].
  - **Wrong:** score **−10**. If asked == 10 → fail, else next question [C].
  - **Fail:** MessageBox "Oyuna baslamak icin gerekli sürücü belgesini alamadiniz. Lutfen tekrar deneyin." / "Uyari" (`0x517380`/`0x517378`, ASCII spelling as in the binary). Then asked=0, correct=0, score=0, wheel x reset, Image5 cleared. No new question is drawn: the last one stays and the next click starts the new round (quirk) [C].
  - The quiz ends as soon as the required count is reached, so with 3 required it can pass after 3 questions [C].
- After passing: when the menu video player is idle, `Image4` is hidden and `Video\cancan.avi` plays in `paVid` (`0x515e60` tail) [L].

## 2. Data\UserData.dat (profile file) — byte exact

Delphi `file of TUser`, record size **0x10F = 271**, packed. Record id N is at offset (N-1)·271 [C] (`0x5345bc`, `0x5346e0`, `0x534760`).

| Off | Size | Type | Field |
|---|---|---|---|
| 0x000 | 4 | int32 LE | id (1-based record number). -1 in memory = new, not yet saved |
| 0x004 | 51 | ShortString[50] (CP1254) | name (Adın) |
| 0x037 | 51 | ShortString[50] | surname (Soyadın) |
| 0x06A | 4 | int32 | age = combobox index+1 (1..100) |
| 0x06E | 51 | ShortString[50] | city (Şehir) |
| 0x0A1 | 4 | int32 | score: value of the live "Puan" at the last save (quiz ±10s accumulate here; maps reset it to 0) |
| 0x0A5 | 1 | byte | licence ever passed (0/1) |
| 0x0A6 | 4 | int32 | maps unlocked (1..4) |
| 0x0AA | 101 | ShortString[100] | key ("anahtar"), see below |

Unused bytes after a ShortString's length are left as written (zeros in a fresh record). Example (`work/wine/game/v2/Data/UserData.dat`): id 1, "Test", "Surucu", age 12, "Ankara", score 0x6e=110 (8 quiz answers ×10 in session 1, +3×10 in session 2), licence 1, unlocked 1, key "00001" [C].

- **Open** (`0x5345bc`): `exe dir + 'Data\UserData.dat'`. If missing → Rewrite, else Reset (record size 271) [C].
- **Save** (`0x534760(rec)`), only if name is non-empty [C]:
  - id == -1: seek to EOF, id = FileSize+1, write.
  - Otherwise seek id-1. If the key is empty → key = current key. Else if `StrToInt('$'+copy(key,1,4))` < current session total → key = current key. Write the record; the in-memory copy gets the updated id/key.
- **Key** (`0x535b3c`) [C]:
  - total T = sum of `0x5531e8[0..3]`.
  - key = `IntToHex(T,4) + IntToHex(c,1)`, where `c = (digitsum(T)*7 + 17) mod 16` and digitsum is the decimal digit sum (`0x535ac4`).
  - T=0 → "00001".
  - Example: T=1350 (0x546), digitsum 9 → c=(63+17)%16=0 → "05460".
- **Save points:** new driver created; map button pressed; map passed with a new unlock (`0x530770`); exit to menu from game (`0x52def4`). Not saved on time-out failure or when the program is killed [C].
- Profiles are never deleted. There is no per-map best score on disk: only the session total, as the key [C].

## 3. In-game flow

### 3.1 Start / map load
- **First map** (`0x52dc8c`):
  - required = `HG.vdd 'Ayarlar-Harita'+N+'Puan'` (ReadInteger, default 200).
  - Reset: score=0, answered-sign list cleared, elapsed=0 (`0x534728`).
  - Runs builder N (`0x52cd5c`/`0x527524`/`0x504eac`/`0x51f80c`/`0x52928c`), then shows the F1 help text [C].
- **Builder:** limit = `Ayarlar-HaritaNSure` (default 240 for map 1, 600 for the others). Shows the "Harita Yükleniyor" loader with `Bolumler\Diger\{Talim,Kasaba,Sehir,SehirMerkezi,Otoban}.jpg` and title "<Map> (Oyun süresi : hh:nn:ss - Toplaman gereken puan : N)" [C].
- **Startup delay:** the cadencer waits until > 500 ms have passed since the first frame (`(now-t0)*24*3600*1000 > 500`, constants `0x52e2c8..d4`). Then it enables `TimerFPS` and queues the greeting speech `sesler\giris\giris001.wav` [C].
- **Shipped values:** Puan 150/350/450/450, Süre 240/600/600/600 s.

### 3.2 Clock, HUD, keys
- `TimerFPS` (default interval 1000 ms, not set in DFM) adds `elapsed += 1.0` per tick while not paused (`0x52eae4`, const `0x52eb04`=1.0) [C].
- HUD (`0x5343ec`, every frame) [C]:
  - "Puan : " + score.
  - "Süre : " + FormatDateTime('hh:nn:ss', elapsed/86400). Counts **up** from 0.
  - Round(player speed) + " km/h".
  - Each text has a "…Golge" shadow copy.
- "Sonraki bölüme geçmek için [F4] tuşuna basın..." (`GLHUDTextSH`) shows when score ≥ required and map ≠ 4. It blinks via `0x5367b4(700,500)`: on 700 ms, off 500 ms [L].
- **Map end trigger** (cadencer `0x52dfec`): when not paused, not in menu mode, no talking animation, no cutscene, and `elapsed ≥ limit` → `MapEnd 0x530770` [C].
- **Keys** (`0x52e2ec`; all are ignored while talking, while a question is open, or while a video panel shows) [C]:
  - **SPACE**, or joystick button 2 in joystick mode: toggles pause. Pausing stops all actors and the clock and enables object picking. Resuming hides the arrow and gives AI cars a random speed `Random(65)+25` (Otoban `Random(10)+90`) and pedestrians 3.0 (`0x5081a8`).
  - **F4**: if not paused and score ≥ required → MapEnd. Not gated by map; works on map 4 even though the hint is hidden.
  - **ESC**: menu mode with ESC flag, then shows the `Menu` question (exit confirmation).
  - **F1**: toggles the controls help `0x52f708`.
  - **F2**: toggles the map info: "Oyun süresi : "+limit+"\r\n"+"Toplaman gereken puan : "+req+"\r\n\r\n"+4 hint lines+"\r\n"+"İyi eğlenceler!...", see `strings.json` hud.
  - **F3**: toggles the "F1 - Oyun Kontrolleri…" hint.
  - **j**: joystick/keyboard toggle message. **k/l/o/t/y**: camera / switch car (not rules). **m/n/z/x**: radio. **h**: horn. **c / v**: left / right signal.
  - **ENTER**: only while the report is visible (§3.6).

### 3.3 Question panel (signs, violators, menu) — `ShowQuestion 0x5332b8(kind, arg)`
- The panel is a set of GLHUDTexts (question `0x55de34`; answer lines `0x55de24/28/2c` + `0x55de30`; shadows `0x55de38..48`). It opens with `0x55de5c`=1.
- The question is "Soru : " + text + " (+" + group*20 + ")", word-wrapped at 60 chars (`WrapText(s,60)`).
- Layout: each line 20 px. Panel top y = 575 − 25·(total lines + 3). The arrow `FormOyun.arrow` points at the clicked object [C].
- Each line's Tag is its answer number in the shuffled table (§1.1): Tag 1 = correct. The `Menu` kind is not shuffled and has no "a ) " prefix.
- **kind "Trafik", arg -1 — traffic sign** [C] (`Ehliyet_MouseDown 0x52eb08`):
  - Requirements: paused, not in menu mode, the picked object's Tag == 1, its class is the sign sprite/plane (`0x494a90`/`0x493b84`), and its material name is `'L'+nn`.
  - Record = SoruBank index NE + nn − 1, i.e. **SoruBank id 71+nn**. The texture is `Bolumler\Diger\TIsaret\LEVHAnn.jpg`. Verified: L37 → id 108 "Bisiklet giremez." group 2 (+40), levha37.jpg is the no-bicycle sign; matches [RT].
  - If the id is beyond the file → debug message "Lehva bigisi bulunamadi : nn".
  - If the id is in the **answered-correctly list** `0x55de60` (cleared at each map start/reset): line 2 shows "Bu soru daha önce soruldu." (Tag 99, no points), speech `bilmistin`, and the game resumes after the speech. Otherwise the arrow is placed over the sign.
- **kind "TrafikX" — violator vehicle / pedestrian** [C] (`0x532c5c`):
  - **Vehicle:** picked object is a `TGLActorTrafik` (`0x536988`) whose owner (`+0x120`) is a TAraba with violation code `owner+0xb0` > 0. Codes: 1 = ran red light, 2 = littering, 3 = wrong parking. The code is set by AI logic — see WorldRE's doc.
  - The code is consumed (`+0xb0` := 0), so each violation can be asked once.
  - A clean car does nothing: no question, no penalty.
  - **Pedestrian** (`TYaya`/`TInsan`): `FUN_00539c78(ped)` returns a non-zero violation that differs from the latched `ped+0x11c` → latch it and ask code 5.
  - The question is synthetic. Text is empty, so the panel shows "Soru :  (+N)". Category `TrafikX`. Answers are below; a1 is the correct one:

  | code | a1 (correct) | a2 | a3 | group → points |
  |---|---|---|---|---|
  | 1 | Bu araç ışık ihlali yaptı. | Bu aracın son muayene süresi geçmiş. | Aracın farları kırık. | 5 → 100 |
  | 2 | Bu araç etrafı kirletiyor. | (same) | (same) | 3 → 60 |
  | 3 | Bu araç yanlış park etmiş. | (same) | (same) | 3 → 60 |
  | 5 | Bu yaya kırmızı ışıkta geçti. | Bu yaya karşıdan karşıya geçerken koşuyordu. | Yaya etrafa çöp attı. | 3 → 60 |
- **Answer click** (same handler, picked object = GLHUDText with Tag ≠ 0, not in menu mode) [C]:
  - Tag 1: score **+ group×20**. Increment the correct counter for kind q = `0x54af1c` value (0 sign, 1/2/3 vehicle code, 5 pedestrian: no counter). If category ≠ `TrafikX`, append the id to the answered list. Speech: `dogru\dNNN` (random 1..30), then for signs `levha\c(id−5).wav`, for violators `trafik\t%03d(code)`.
  - Tag 2/3: score **−10**, increment the wrong counter for kind q, speech `yanlis\yNNN` and then the same explanation clip. Wrong sign answers are not recorded, so the sign can be asked again.
  - Tag 99: nothing.
  - Then the talking animation plays and the game un-pauses when it ends (`ActorAnimEndFrameReached 0x52f2b4` / `0x50a7e4`) [C].

### 3.5 Map end — `MapEnd 0x530770` (time out or F4)
- **score < required → failed** [C]:
  - Reset score=0, the answered list and elapsed=0.

## 4. SoruBank in game
- `Data\SoruBank.dat`, record 1310 bytes [C] (`0x534234`):
  - int32 id @0; question ShortString[255] @4; a1 @0x104 (correct), a2 @0x204, a3 @0x304; category ShortString[20] @0x404; group byte @0x419.
  - If the file is missing: MessageBox "Soru bankası bulunamadi." / "Hata".
- ids 1..71 = Ehliyet (licence quiz, group 1). ids 72..150 = Trafik (signs): groups 1×8, 2×31, 3×33, 4×5, 5×2.
- Sign nn ↔ id 71+nn ↔ `LEVHAnn.jpg` ↔ speech `sesler\levha\c(66+nn).wav` (c67..c144 shipped; id 150's c145 is missing).
- Points = 20×group. The licence quiz ignores group: always ±10 [C].
